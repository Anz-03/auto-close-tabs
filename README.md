# 闲置标签自动关闭 · Auto Close Tabs

一个仿 Arc 思路的标签自动清理扩展。纯 JavaScript，Manifest V3，无依赖、无构建步骤，适用于 Chrome 120+ 和支持相同 API 的新版 Edge。

## 安装

1. Chrome 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本项目目录 `auto_close`。
4. 从工具栏打开「闲置标签自动关闭」，设置规则并保存。也可将扩展固定在工具栏。

## 规则

- 默认启用，总数上限 **20** 个，闲置门槛 **20** 分钟；两者可在弹窗修改并保存，立即生效。总数范围 1–10000，闲置范围 1–10080 分钟。
- 总数统计所有普通浏览器窗口，**固定 + 未固定** 一起计数。弹出式窗口不参与，默认不启用无痕访问。
- 仅在 `总数 > 上限` 时清理。按最久未访问顺序关闭达到闲置门槛的未固定标签，降至上限立即停止。
- 固定标签、每个窗口当前选中的标签始终保留。默认也保留正在播放声音的标签，可取消声音保护。
- 如果没有满足条件的标签，就暂时超限，绝不为了凑足数量强制关闭最近使用的标签。固定标签本身超过上限时，也不会关闭固定标签。
- 切换离开一个标签后开始计算闲置时间，长时间停留阅读不会导致刚离开就被关闭。取消固定或移动到另一窗口会重新给予闲置宽限期。
- 可在浏览器右键菜单中固定标签，也可在扩展弹窗中固定。弹窗的开关立即启用 / 暂停；数值和声音保护设置点击「保存规则」后生效。
- 创建、切换、关闭、固定等事件触发检查，另外每 30 秒检查一次。浏览器可能延后后台定时任务；睡眠期间不会唤醒设备，所以不保证到点精确关闭。
- 「立即检查」沿用相同规则，暂停时不会关闭标签。

## 数据与恢复

设置保存在 `storage.local`；活动记录保存在 `storage.session`，可跨后台 worker 重启，浏览器重启、扩展重载后清空并重新给予完整闲置时限。没有服务器、网络请求或内容脚本，不读取页面正文；`tabs` 权限用于列出标题及管理标签。

关闭会真正移除标签，不是休眠或隐藏。需要时可用浏览器「重新打开关闭的标签页」（macOS：`⌘⇧T`，Windows：`Ctrl+Shift+T`）；页面中的未保存输入是否能恢复取决于浏览器及网页。扩展不会读取或判断表单是否有未保存内容，重要页面请固定。

## 开发与验证

使用 Node.js 18+：

```sh
npm test
```

15 项自动化测试已通过，包含计数与 LRU、闲置边界、固定 / 活跃 / 音频豁免、动态设置、后台重启、启动宽限、串行清理和删除前重新检查。另在隔离的真实 Edge 浏览器中验证了扩展加载、中文界面、保存规则、暂停 / 启用、原生固定，以及等待一分钟后的实际关闭：旧的未固定标签被关闭，固定与当前选中标签保留，数量恰好回到上限。Chrome 尚未单独进行浏览器实测。

可按以下步骤重复验收：

1. 将上限改为 3、闲置改为 1 分钟，打开 5 个测试标签，其中固定 1 个。
2. 保持一个未固定标签选中，等待约 1–1.5 分钟，确认最旧的后台标签被关闭，剩下 3 个。
3. 切换刚阅读超过一分钟的标签，确认它离开后还有完整一分钟宽限。
4. 检查跨窗口计数、固定豁免、播放声音保护和暂停开关。
5. 在扩展管理页停止后台 worker，确认下次检查能继续；重启浏览器确认获得新宽限期。

实现参考：[Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs)、[Alarms API](https://developer.chrome.com/docs/extensions/reference/api/alarms)、[Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)。
