闲置标签自动关闭 · 隐私政策

开发者：anz_03。

适用版本：1.0.2。生效日期：2026 年 10 月 17 日。

处理哪些信息

扩展在本地通过浏览器标签 API 读取普通窗口中标签的 ID、窗口 ID、标题、固定状态、选中状态、播放声音状态和最近访问时间，用于显示标签列表及决定何时关闭闲置标签。tabs 权限还允许浏览器提供标签网址等元数据，但本扩展不将网址用于分析、存储或传输。不读取网页正文、表单输入、Cookie、密码或浏览历史数据库。

保存位置及保留时间

启用状态、标签总数上限、闲置时限及声音保护设置保存在浏览器本地存储 storage.local 中，直至用户修改或卸载扩展。标签活动时间和当前选中标签的 ID 保存在 storage.session 中，可跨后台进程重启保留；浏览器重启、扩展停用或重新加载时会清空。标签关闭后，其活动记录会在下一次状态同步时删除。标题不被扩展持久保存。

传输、共享和用途

本版本不向开发者或第三方服务器发送上述信息，不使用分析统计、广告、跟踪器或远程代码，不出售或共享用户数据。扩展内没有账号系统或支付功能。信息仅用于用户可见的标签管理和自动关闭功能。

用户控制

用户可以暂停自动清理、修改规则、固定标签以豁免关闭，或卸载扩展。卸载会删除扩展的本地设置和会话记录。已经被关闭的标签及其恢复记录由浏览器管理，不由本扩展保存。

政策更新和联系

如果后续版本改变数据处理方式，本政策会同步更新。关于本扩展的数据处理问题，请通过 GitHub Issues 联系开发者。请不要在公开问题中提交密码、完整浏览记录或其他私人资料。
